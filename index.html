📋 Step-by-Step Guide 📋 دليل خطوة بخطوة

Follow every step carefully. Each command matters. Don't skip any step. اتبع كل خطوة بعناية. كل أمر مهم. لا تتخطى أي خطوة.

1
Download F-Droid تحميل F-Droid
Install the open-source app store — the only safe place to get Termux. ثبّت متجر التطبيقات مفتوح المصدر — المكان الوحيد الآمن للحصول على Termux.

Open your tablet's browser and go to https://f-droid.org. You will see a blue and white homepage with a big "Download F-Droid" button. افتح متصفح جهازك اللوحي وانتقل إلى https://f-droid.org. ستجد صفحة رئيسية زرقاء وبيضاء مع زر "Download F-Droid" كبير.

⚠️ Warning you'll see:تحذير ستظهر:
"This file may harm your device" — This is a normal Android warning for APK files from outside the Play Store. Tap OK or Download anyway. F-Droid is 100% safe and open source. "هذا الملف قد يضر جهازك" — هذا تحذير أندرويد عادي لملفات APK من خارج متجر Play. انقر حسناً أو التنزيل على أي حال. F-Droid آمن 100% ومفتوح المصدر.

Enabling Unknown Sources (one-time setup):تفعيل المصادر غير المعروفة (إعداد مرة واحدة):

  1. Android will ask: "Allow your browser to install apps?"سيسألك أندرويد: "هل تسمح للمتصفح بتثبيت التطبيقات؟"
  2. Go to: Settings → Security → Install unknown apps → [Your Browser] → Allowاذهب إلى: الإعدادات ← الأمان ← تثبيت تطبيقات غير معروفة ← [متصفحك] ← السماح
  3. Come back and tap the downloaded APK file in your notifications or Downloads folderارجع وانقر على ملف APK المحمّل في الإشعارات أو مجلد التنزيلات
  4. Tap Install → Doneانقر تثبيت ← تم
✅ F-Droid is now installed. You should see its icon: a small blue robot.F-Droid مثبّت الآن. يجب أن ترى أيقونته: روبوت أزرق صغير.
2
Install Termux from F-Droidتثبيت Termux من F-Droid
Get the real Termux — not the outdated Play Store version.احصل على Termux الحقيقي — ليس النسخة القديمة في متجر Play.
  1. Open F-Droid app from your home screenافتح تطبيق F-Droid من الشاشة الرئيسية
  2. Wait for it to say "Updating repositories..." (takes 30–60 seconds). This downloads the list of available apps.انتظر حتى يقول "جاري تحديث المستودعات..." (يستغرق 30–60 ثانية). هذا يحمّل قائمة التطبيقات المتاحة.
  3. Tap the 🔍 Search icon and type: Termuxانقر أيقونة 🔍 البحث واكتب: Termux
  4. Find the one by Fredrik Fornwall — it has a black terminal iconابحث عن التطبيق من Fredrik Fornwall — يحمل أيقونة طرفية سوداء
  5. Tap Install and wait. Then tap Open.انقر تثبيت وانتظر. ثم انقر فتح.
🚫 Never install Termux from Google Play Store! That version is abandoned and outdated. Always use F-Droid.لا تثبّت Termux أبدًا من متجر Google Play! تلك النسخة متوقفة وقديمة. استخدم F-Droid دائمًا.
3
First Time Opening Termuxفتح Termux للمرة الأولى
Understanding the terminal interface — don't be scared!فهم واجهة الطرفية — لا تخف!

When you open Termux for the first time, you'll see a completely black screen with some text loading, then a prompt. This is perfectly normal — it's a terminal emulator, your gateway to Linux. عند فتح Termux للمرة الأولى، سترى شاشة سوداء مع نص يتحمّل ثم مؤشر. هذا طبيعي تمامًا — إنها محاكي طرفية، بوابتك لنظام لينكس.

You will see something like this:ستجد شيئًا كهذا:

terminal output 
Welcome to Termux!
Community forum:  https://termux.com/community
Gitter chat:      https://gitter.im/termux/termux
IRC channel:      #termux on libera.chat

$ _
💡
What does $ mean?ماذا يعني $؟
The $ symbol is the command prompt. It means Termux is ready and waiting for you to type a command. You don't type the $ — only what comes after it. رمز $ هو مؤشر الأوامر. يعني أن Termux جاهز وينتظر كتابة أمر. لا تكتب $ — اكتب فقط ما يأتي بعده.
4
Update Termux Packagesتحديث حزم Termux
Always update first — this fixes bugs and prepares Termux for installs.قم بالتحديث دائمًا أولًا — يصلح الأخطاء ويهيئ Termux للتثبيتات.

Type the following command and press Enter:اكتب الأمر التالي واضغط Enter:

bash 
pkg update && pkg upgrade

Termux will download the latest package list. You'll see lots of text scrolling. Then it will ask:سيقوم Termux بتنزيل أحدث قائمة حزم. ستجد نصًا كثيرًا يمر. ثم سيسأل:

terminal prompt
Do you want to continue? [Y/n]
💡 Type y and press Enter to confirm. If you see another prompt, type y again. Wait until you see the $ prompt again — this can take 2–4 minutes depending on your internet speed.اكتب y واضغط Enter للتأكيد. إذا ظهر مطالبة أخرى، اكتب y مرة أخرى. انتظر حتى يعود مؤشر $ — قد يستغرق 2–4 دقائق حسب سرعة الإنترنت.
5
Install proot-distroتثبيت proot-distro
The magic tool that lets you run a real Linux OS inside Termux, without root.الأداة السحرية التي تتيح تشغيل نظام لينكس حقيقي داخل Termux، بدون روت.
bash
pkg install proot-distro

When asked Do you want to continue? [Y/n] — type y and press Enter. The installation takes about 30–60 seconds.عند السؤال Do you want to continue? [Y/n] — اكتب y واضغط Enter. يستغرق التثبيت 30–60 ثانية.

💡 proot-distro is like a container system. It creates an isolated Linux environment where you can install full Linux packages without modifying Android's system files.proot-distro يشبه نظام الحاويات. يُنشئ بيئة لينكس معزولة حيث يمكنك تثبيت حزم لينكس كاملة بدون تعديل ملفات نظام أندرويد.
6
Install Ubuntu Linuxتثبيت أوبونتو لينكس
Download and set up a full Ubuntu environment. ⏱ 2–5 min تنزيل وإعداد بيئة أوبونتو كاملة. ⏱ 2–5 دقائق
bash
proot-distro install ubuntu

You'll see a download progress bar like this:ستجد شريط تقدم التنزيل مثل هذا:

terminal output
[*] Downloading distribution rootfs...
[*] Extracting rootfs, please wait...
[*] Configuring Ubuntu...
[*] Done installing Ubuntu.
⚠️ Keep your screen on! Don't let the tablet sleep during this download. This installs a ~100MB base Ubuntu system — it may take 2–5 minutes on a good connection.أبقِ الشاشة مضاءة! لا تتركها تنام أثناء التنزيل. يثبّت هذا نظام أوبونتو أساسي ~100 ميغابايت — قد يستغرق 2–5 دقائق مع اتصال جيد.
7
Enter Ubuntuالدخول إلى أوبونتو
Log in to your Linux system — this is where the real work happens.سجّل الدخول إلى نظام لينكس — هنا يبدأ العمل الحقيقي.
bash
proot-distro login ubuntu

Watch the prompt change! You'll notice it changes from $ to something like:لاحظ تغيّر المؤشر! ستجده يتغير من $ إلى شيء مثل:

terminal
root@localhost:~# _
🎉
You're now inside real Ubuntu Linux!أنت الآن داخل أوبونتو لينكس الحقيقي!
The # symbol means you're the root (administrator) user. root@localhost:~ means: you are root user, on a computer named localhost, in the home directory ~. رمز # يعني أنك المستخدم root (المدير). root@localhost:~ يعني: أنت المستخدم root، على جهاز اسمه localhost، في المجلد الرئيسي ~.
8
Update Ubuntuتحديث أوبونتو
Update the Ubuntu package lists and upgrade everything.حدّث قوائم حزم أوبونتو وقم بترقية كل شيء.
bash
apt update && apt upgrade

When prompted with [Y/n], type y and press Enter. If asked about keeping or replacing config files, press Enter to accept the default.عند المطالبة بـ [Y/n]، اكتب y واضغط Enter. إذا سُئلت عن الاحتفاظ بملفات الإعداد أو استبدالها، اضغط Enter لقبول الافتراضي.

💡 apt update refreshes the list of available packages. apt upgrade downloads and installs the newer versions. Always run both together.apt update يُحدّث قائمة الحزم المتاحة. apt upgrade يحمّل ويثبّت النسخ الأحدث. شغّلهما معًا دائمًا.

Install Essential Toolsتثبيت الأدوات الأساسية
curl, wget, git, and nano — your developer toolbelt.curl وwget وgit وnano — حزامك الأدواتي كمطور.
bash
apt install curl wget git nano -y

The -y flag automatically answers "yes" to all prompts. Here's what each tool does:الخيار -y يجيب تلقائيًا بـ "نعم" على جميع المطالبات. إليك ما يفعله كل أداة:

  • curl — Downloads files and runs scripts from URLsيحمّل الملفات ويشغّل سكريبتات من روابط URL
  • wget — Another download tool, simpler and great for large filesأداة تنزيل أخرى، أبسط وممتازة للملفات الكبيرة
  • git — Version control system to clone and manage code projectsنظام التحكم بالإصدار لاستنساخ وإدارة مشاريع الكود
  • nano — A simple, beginner-friendly text editor that runs in the terminalمحرر نصوص بسيط ومناسب للمبتدئين يعمل في الطرفية

code-server requires Node.js to run. We'll install the LTS version.يحتاج code-server إلى Node.js للعمل. سنثبّت نسخة LTS.

expected output

Install code-server (VS Code)تثبيت code-server (VS Code)
The main event! Installing VS Code as a web server. ⏱ 5–15 min الحدث الرئيسي! تثبيت VS Code كخادم ويب. ⏱ 5–15 دقيقة
bash
npm install -g code-server
🔴
CRITICAL: Do NOT close Termux!هام جداً: لا تغلق Termux!
This command downloads and compiles VS Code, which can take 5–15 minutes. Keep your screen on, keep Termux in the foreground, and make sure your internet stays connected. If it fails partway, simply re-run the same command — it will resume. هذا الأمر يحمّل ويُجمّع VS Code، وقد يستغرق 5–15 دقيقة. أبقِ شاشتك مضاءة، أبقِ Termux في المقدمة، وتأكد من استمرار الاتصال بالإنترنت. إذا فشل في المنتصف، أعد تشغيل الأمر نفسه — سيستأنف من حيث توقف.

You'll see a lot of text about packages being downloaded. Near the end, you'll see:ستجد نصًا كثيرًا عن الحزم المحمّلة. في النهاية، ستجد:

expected output

found 0 vulnerabilities
12
Configure code-serverضبط code-server
Set it to run without a password, and bind to localhost.اضبطه للعمل بدون كلمة مرور، ومرتبطًا بـ localhost.

Step 1: Run code-server once to generate the config file, then press Ctrl+C to stop it:الخطوة 1: شغّل code-server مرة لإنشاء ملف الإعداد، ثم اضغط Ctrl+C لإيقافه:

bash
code-server

Wait 5 seconds, then press Ctrl+C to stop it. Now edit the config:انتظر 5 ثوانٍ، ثم اضغط Ctrl+C لإيقافه. الآن عدّل الإعداد:

bash
nano ~/.config/code-server/config.yaml

You'll see nano text editor open. The file currently looks like:سيفتح محرر nano. يبدو الملف حاليًا كهذا:

❌ BEFORE / قبل
bind-addr: 127.0.0.1:8080
auth: password
password: abc123xyz
cert: false
✅ AFTER / بعد
bind-addr: 127.0.0.1:8080
auth: none
cert: false

Make those two changes: change password to none, and delete the password: ... line entirely.قم بهذين التغييرين: غيّر password إلى none، واحذف سطر password: ... بالكامل.

💾
How to save in nano:كيفية الحفظ في nano:
1. Press Ctrl+X to exit
2. Press Y to confirm save
3. Press Enter to keep the filename 1. اضغط Ctrl+X للخروج
2. اضغط Y للتأكيد على الحفظ
3. اضغط Enter للاحتفاظ باسم الملف

❓ Frequently Asked Questions ❓ الأسئلة الشائعة

Everything you might be wondering about. كل ما قد تتساءل عنه.

Does this damage my Android device?هل هذا يضر جهاز أندرويد؟ ▼
Absolutely not. proot-distro creates a completely isolated Linux environment inside Termux. It cannot modify Android's system files, it requires no root access, and it can be completely removed by simply uninstalling Termux from your device. Your Android system remains 100% safe. بالطبع لا. يُنشئ proot-distro بيئة لينكس معزولة تمامًا داخل Termux. لا يستطيع تعديل ملفات نظام أندرويد، ولا يتطلب صلاحيات روت، ويمكن إزالته كليًا بمجرد إلغاء تثبيت Termux من جهازك. يبقى نظام أندرويد آمنًا 100%.
Will code-server work on my tablet with 2GB RAM?هل سيعمل code-server على جهازي اللوحي بـ 2 جيجابايت RAM؟ ▼
Yes, but performance may be limited. code-server works best with 3GB+ RAM. On 2GB devices, close all background apps before starting. The editor itself will run, but some heavy extensions might be slow. Most basic web development, Python, and JavaScript projects will work fine. نعم، لكن الأداء قد يكون محدودًا. يعمل code-server بأفضل أداء مع 3 جيجابايت RAM أو أكثر. على الأجهزة التي تملك 2 جيجابايت، أغلق جميع التطبيقات الخلفية قبل البدء. المحرر نفسه سيعمل، لكن بعض الإضافات الثقيلة قد تكون بطيئة. معظم مشاريع تطوير الويب وPython وJavaScript ستعمل بشكل جيد.
Can I install VS Code extensions?هل يمكنني تثبيت إضافات VS Code؟ ▼
Yes! code-server uses the Open VSX marketplace (instead of Microsoft's marketplace) to install extensions. Most popular extensions are available: Python, JavaScript/TypeScript, Prettier, ESLint, GitLens, and thousands more. Click the Extensions icon (four squares) in VS Code and search just like you would on desktop. نعم! يستخدم code-server متجر Open VSX (بدلًا من متجر Microsoft) لتثبيت الإضافات. معظم الإضافات الشهيرة متاحة: Python وJavaScript/TypeScript وPrettier وESLint وGitLens وآلاف غيرها. انقر أيقونة الإضافات (أربعة مربعات) في VS Code وابحث كما تفعل على سطح المكتب.
My files — where are they saved?ملفاتي — أين تُحفظ؟ ▼
Your files are saved inside the Ubuntu environment, at /root/ (or wherever you create them). They persist between sessions — you don't lose them when you close Termux, only if you uninstall Termux or run proot-distro remove ubuntu. To access Android's storage, you can use Termux's storage access, but this is an advanced topic. ملفاتك تُحفظ داخل بيئة أوبونتو، في /root/ (أو أينما تُنشئها). تبقى بين الجلسات — لا تفقدها عند إغلاق Termux، فقط إذا ألغيت تثبيت Termux أو شغّلت proot-distro remove ubuntu. للوصول إلى تخزين أندرويد، يمكنك استخدام وصول تخزين Termux، لكن هذا موضوع متقدم.
Can I use this without internet once set up?هل يمكنني استخدامه بدون إنترنت بعد الإعداد؟ ▼
Yes! Once code-server is installed and configured, you can use it completely offline. You don't need internet to run VS Code — just run the 3 startup commands and open your browser. Internet is only needed to install new extensions or packages. نعم! بعد تثبيت code-server وضبطه، يمكنك استخدامه دون إنترنت تمامًا. لا تحتاج الإنترنت لتشغيل VS Code — فقط شغّل أوامر البدء الثلاثة وافتح متصفحك. الإنترنت مطلوب فقط لتثبيت إضافات أو حزم جديدة.
Why use F-Droid instead of Play Store for Termux?لماذا F-Droid بدلًا من متجر Play لتثبيت Termux؟ ▼
The Termux on Google Play Store has been frozen since 2022 and receives no updates. It has security vulnerabilities and missing features. The F-Droid version is actively maintained and up-to-date. Using the Play Store version will cause failures in later steps of this guide. Always use F-Droid. نسخة Termux على متجر Google Play متوقفة منذ 2022 ولا تتلقى أي تحديثات. تحتوي على ثغرات أمنية وميزات مفقودة. نسخة F-Droid يتم صيانتها بنشاط وهي محدّثة. استخدام نسخة متجر Play سيتسبب في فشل الخطوات اللاحقة في هذا الدليل. استخدم F-Droid دائمًا.
How do I update code-server in the future?كيف أحدّث code-server في المستقبل؟ ▼
Enter Ubuntu and run: npm install -g code-server@latest. This will upgrade to the latest version. You can check your current version by running code-server --version. ادخل أوبونتو وشغّل: npm install -g code-server@latest. سيرقّي إلى أحدث نسخة. يمكنك التحقق من نسختك الحالية بتشغيل code-server --version.
